# Marathon Tests

Repositório com exercícios e soluções de programação resolvidos como parte da minha rotina de treino ("maratona") de lógica e estruturas de dados.

## Sobre

Cada problema presente aqui foi retirado da plataforma [LeetCode](https://leetcode.com/). O objetivo deste repositório é registrar minha evolução, guardar as soluções que encontrei e servir de material de consulta para revisão futura.

## Estrutura

Cada arquivo corresponde a um problema resolvido. O nome geralmente segue o título do exercício no LeetCode, para facilitar a busca. O código e os comentários estão em inglês.

```
marathon-tests/
├── nome-do-problema-1.c
├── nome-do-problema-2.java
├── nome-do-problema-3.py
└── ...
```

## Sobre as soluções

- As soluções aqui são de minha autoria, feitas como exercício de prática.
- O enunciado original de cada problema pertence ao LeetCode e pode ser consultado diretamente na plataforma.
- Podem existir comentários no código explicando o raciocínio ou a complexidade da solução (Big-O).

## Como usar

Sinta-se à vontade para clonar o repositório e testar as soluções:

```bash
git clone https://github.com/SEU-USUARIO/marathon-tests.git
```
